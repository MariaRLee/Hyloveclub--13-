Hyloveclub - Shanghai Old Mahjong (13 Tiles) / 海納福上海老麻將（13張）

Upload index.html to the root of a public GitHub repository, enable Settings > Pages > Deploy from branch / main / root.
Use the same URL on desktop, iPhone Safari and Android Chrome. Toggle English / 中文 inside the game.
This is a standalone HTML game without network/CDN dependencies, and based on Ching Lee's original Shanghai Old Mahjong rules (see in-game link). The 136-tile no-bonus rules are used.

Updates in v2: approved visual symbols for 34 tile faces (Characters, Dots, Bamboos, Winds, Dragons); English/Chinese controls, scoring and game outcome; bilingual instructions; compact three-bot desktop top row; controls directly beneath your hand; mobile responsive layout.

Game is an educational digital adaptation: not all rare special hands, eight-round rotations, full liability/payment exceptions are implemented. No real-money play.
