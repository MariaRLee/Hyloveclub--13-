Hyloveclub - 上海老麻將（13 張）
版本：v1.0　2026-10-26

上線方式
1. 在 GitHub 建立公開 repository（例如：shanghai-old-mahjong）。
2. 從 ZIP 解壓後，將 index.html 上傳到 repository 根目錄。
3. GitHub Settings > Pages > Deploy from a branch > main / (root) > Save。
4. 公開的 GitHub Pages 網址可以用 iPhone Safari、iPad 或電腦瀏覽器直接開啟。
5. 請上傳真正的 index.html，不要直接上傳 ZIP 檔。

已支援
- 4 人 13 張：一位真人與三位電腦；傳統 136 張（不加花／寶）。
- 摸、打、吃（僅上家）、碰、明槓、暗槓、加槓、胡、過。
- 依胡牌優先、碰槓優先於吃的流程處理。
- 番數最低 11 番；符合成葫特殊牌型可按固定葫數結算。
- 自摸：其餘 3 家各付全部葫數；放炮：放炮者全額，另兩家各付半額。
- 籌碼預設每人 300,000 葫；連續多手、不同莊家與簡易圈風追蹤。
- 基本番種：莊家、門清、一摸七、對對胡、平胡、一般高、老少、缺門、斷么、缺五、三五、五門齊、混一色、七對子、仙門碰、風圈／風位碰、暗嵌、槓、獨聽等（含部分組合判定）。
- 特殊成葫：清一色、大三元、小三元、大四喜、小四喜、十三么、雙龍抱、清一色對對胡、大三元對對胡、全字碰、全么碰、萬福、長祿、圓壽、三風碰等。
- 出牌提示（啟發式，非保證最佳）、練習清一色胡牌、胡牌明細、四家籌碼、自動保存單機進度。
- 電腦版適合一屏操作，手機版觸控版面。

重要限制
- 本版是「可操作的教學／文化推廣初版」，不是原手稿所有番種／成葫／八圈賽制的完整數位實現。
- 尚未完整實作特殊搶槓、相公復活、天聽地聽宣示、三副落／四副落包牌、洗牌包牌、連莊費、八圈換位，及部分罕見的成葫牌型。
- 碰槓補牌、含槓的組合番種採電子版簡化流程；是否完全符合作者細節仍需逐項核對。
- 原規則表「800,00」作為 80,000 葫處理，原始數字有印刷歧義。
- 多種「成葫」相互包含時，取較高進階組合，無包含關係者可累積；這是初版去重方式，需與原作者確認。
- 不使用真錢或賭注。
